# Hardware

Hier kommen die Schaltpläne hin, sobald sie gezeichnet sind:

- Stromversorgung mit Selbsthaltung und Wächterschaltung (Erschütterungsschalter)
- Optokoppler-Eingänge für Blinker, Fernlicht, Leerlauf, Zündung
- Drehzahl-Aufbereitung vom Zündkabel
- Verkabelung der I²C-Module und Stecker-Belegung

Grundlage ist Abschnitt 2 bis 4 in [../docs/bauplan.md](../docs/bauplan.md).
