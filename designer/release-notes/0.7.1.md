SD-Karte unter Windows.

## Behoben

- **Auf SD-Karte schreiben** ging unter Windows nicht („Name is not allowed“): Edge und Chrome lassen keine Dateien mit der Endung `.cfg` anlegen. Jetzt schreibt der Designer selbst auf die Karte. Er findet eingesteckte Karten von allein, die Nachfrage des Browsers entfällt. Ein Ordner lässt sich auch von Hand eintragen.
- **Tacho-Einstellungen → Als Datei speichern** schreibt die `tacho.cfg` jetzt ebenfalls direkt in einen Ordner (Karte oder Dokumente) statt über einen Download, den Edge blockieren würde.

Sonst wie 0.7.0 (Taste, Musik-Quellen, Lenkertaster).

## Stand der Tests

Am PC unter Linux mit einem Ordner statt einer Karte geprüft, die Laufwerkssuche läuft beim Bauen unter Windows durch. Mit einer echten Karte unter Windows noch nicht getestet.
