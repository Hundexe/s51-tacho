Erste Vorabversion des PC-Programms für den S51-Tacho.

## Herunterladen

- **S51-Designer.exe**: das Programm für Windows, ohne Installation. Einfach herunterladen und starten.
- **klar.s51**: das mitgelieferte Layout „Klar“ zum Öffnen im Designer.
- **tacho.cfg**: Vorlage der Konfiguration mit allen Einstellungen und Erklärungen.

## Beim ersten Start

Die exe ist nicht digital signiert. Windows zeigt deshalb „Der Computer wurde durch Windows geschützt“. Auf **Weitere Informationen** und dann **Trotzdem ausführen** klicken. Manche Virenscanner melden Programme, die mit PyInstaller gebaut sind, fälschlich. Der Quellcode liegt vollständig im Repo, die exe wird automatisch auf GitHub daraus gebaut (`.github/workflows/designer-release.yml`).

## Was drin ist

- Elemente frei auf dem 480 × 320-Display platzieren: Text, Wert, Balken, Rundinstrument, Kontrollleuchte, Fläche/Linie
- Mehrere Seiten und Nachtversionen
- Eigenschaften wie Datenquelle, Farben, Schrift und Warnschwellen
- Vorschau mit laufenden Demo-Werten
- Rückgängig/Wiederholen, Raster, Tastatursteuerung
- Export auf SD-Karte (Ordner `s51`)
- Drahtlose Übertragung per WLAN
- Bearbeiten der Tacho-Konfiguration
- Dateiformat S51L 1.0

## Bekannte Einschränkungen

- **Vorabversion:** Die Oberfläche wurde noch nicht auf einem echten Bildschirm getestet, nur ihre Logik in automatischen Tests. Darstellungsfehler bitte als Issue melden.
- Die Firmware kann Layouts noch nicht anzeigen. Bisher gibt es dort nur den Decoder. Export und Übertragung lassen sich mit dem simulierten Tacho ausprobieren (siehe `docs/uebertragung.md`).
- Die Schriften in der Vorschau sehen anders aus als auf dem Tacho. Positionen, Größen, Farben und Werte stimmen.
